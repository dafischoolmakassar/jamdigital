Jadwal Sholat Hari Ini (Manual)

Ini yang dibaca kiosk sekarang. Isi manual per hari/bulan (mis. dari jadwal Kemenag setempat). Integrasi auto-fetch API di bawah masih rencana Fase berikutnya — kalau sudah aktif nanti, field ini yang akan terisi otomatis.

Sumber Jadwal (API) — Rencana Fase Berikutnya

Jadwal diambil otomatis dari Aladhan API berdasarkan koordinat masjid. Nilai di bawah dipakai kiosk untuk fetch harian.

Koreksi Manual (Ihtiyat)

Selisih menit yang ditambahkan/dikurangi dari hasil API, supaya cocok dengan jadwal resmi Kemenag setempat.

Satuan: menit. Boleh negatif (mis. -1) kalau hasil API lebih lambat dari jadwal resmi.
